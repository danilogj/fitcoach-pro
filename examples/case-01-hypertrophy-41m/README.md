# Case 01 — Hypertrophy, male 41, detrained intermediate

A real case, published with consent, anonymized. Numbers are unchanged.

**Status: block in progress.** The 8-week block started on 2026-08-31. What is published here is everything that exists at the start of a block — intake, program, nutrition target and baseline assessment. **The training log is not here because it does not exist yet.** It gets published when there are weeks of data to publish, and the log analysis with it.

That gap is deliberate. Every methodology looks convincing in a case study written after the outcome is known.

## What this case shows

| Decision | Where it came from |
| :--- | :--- |
| Upper/Lower 4× instead of a bro split | Available days (4) and the volume-distribution principle, `01-principles.md` |
| Barbell on the back only one day a week | Age 41 plus the axial-load principle — the limiter is connective tissue, not muscle |
| Supported row instead of bent-over row on Monday | Same back volume at zero spinal cost the day before squat day |
| 84 hard sets/week, not 110 | Volume with room to grow — starting at the ceiling leaves nothing to add in week 12 |
| Pec deck instead of a third weekly press | A third horizontal push adds little; the machine can be taken to failure safely |
| 2,700 kcal, surplus of ~350 | Two independent BMR equations converging, plus a component-based maintenance estimate |
| Body fat read as 21-23%, not the 18.7% on the screen | The reading was taken off protocol — fed and hydrated, in the afternoon |

## The audit that started this

This methodology came out of auditing an AI-generated training report that was full of false precision: body fat to one decimal place from a wrist sensor, calorie targets to the single digit, indirect set fractions presented as physiological fact.

The corrections that survived that audit are the reason several rules in this repository are written as warnings rather than recommendations. `06-body-assessment.md` exists almost entirely because of it.
