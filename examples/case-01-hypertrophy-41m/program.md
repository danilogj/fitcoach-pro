# Program — Client A

**Block:** 1 · **Runs:** 2026-08-31 to 2026-10-25 (8 weeks) · **Split:** Upper/Lower ×2 · **Goal:** hypertrophy

## Rules for this block

1. **RIR.** Heavy barbell compounds and pull-ups at 1-2, never to failure · isolation, machines and cables at 0-1.
2. **Axial load on Tuesday only.** Barbell on the back one day a week. At 41 the limiter is joint and connective tissue.
3. **Ramp warm-up** before working sets of squat, RDL, bench and pull-ups: 50% · 70% · 85%, 3-5 reps. Four minutes.
4. **Double progression.** Top of the rep range on every set at target RIR → add load next session.
5. **Supported row, not bent-over row, on Monday.** Same back volume, zero spinal cost the day before squats.

## Periodization

| Weeks | Phase |
| :-: | :--- |
| 1-3 | Introduction — one set fewer per exercise, floor of 2 |
| 4-6 | Full volume |
| 7 | Deload — 2 sets per exercise, RIR 3-4, load held |
| 8 | Reassessment — loads, volume, body composition |

## Contingencies

**No energy — cut in this order:** arm isolation (7a/7b) → second shoulder exercise → core → one set per accessory → one set per compound. Never cut the first exercise of the day.

**Missed days:** 3 days available → odd week Upper A · Lower A · Upper B, even week Lower A · Upper B · Lower B. 2 days → odd week Upper A · Lower A, even week Upper B · Lower B. Missed the whole week → resume at the previous week's volume.

**Substitutions:**

| If unavailable / painful | Use |
| :--- | :--- |
| Pull-up (under 6 reps) | Negatives, 4 s descent — or lat pulldown until he gets there |
| Squat irritating knee or back | Bulgarian split squat 4×8-10/leg |
| Pulley or machine occupied | One-arm row · chest-supported reverse flye · skull crusher |
| Incline bench occupied | Standing bent-over reverse flye, torso at 45° |
