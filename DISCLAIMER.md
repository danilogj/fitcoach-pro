# ⚠️ Read this before installing

**FitCoach Pro is a decision-support tool for certified fitness professionals. It is not a coach, not a medical device, and not a substitute for your professional judgment.**

## 1. You are the responsible professional. Always.

Whoever assesses, prescribes and supervises is you — the certified professional. The author of this repository is not, under any circumstance, the technical authority behind what you prescribe to a client.

## 2. AI hallucinates — and it does so with a straight face

Language models invent numbers, loads, set volumes, calorie calculations, exercise names, contraindications and scientific references, and present all of it with the same confidence as the parts that are correct. This is called hallucination. It is inherent to the technology, not a defect of this project, and **no update will eliminate it**.

This repository is a set of instructions that makes the model's output more consistent and easier to audit. It does not make the model correct.

## 3. Review everything before it reaches a client

Every workout sheet, program, calculation and report produced with this tool must pass through your eyes before it reaches anyone. Exercise selection against the client's history and available equipment, volume, intensity, contraindications, arithmetic — all of it. Handing over unreviewed output means taking the entire risk alone.

## 4. Stay inside your scope of practice

Individualized dietary prescription is restricted to registered dietitians in many jurisdictions, Brazil included (Lei nº 8.234/1991). This project produces **macronutrient targets and nutrition education**. Refer out when the case calls for it.

## 5. This does not diagnose and does not clear anyone to train

The screening module tells you when to refer. Medical clearance is a physician's call, never yours and never the model's.
